MeterTrack

MeterTrack — это приложение для учета показаний счетчиков воды и электроэнергии. Оно позволяет удобно вводить и сохранять данные о счетчиках, хранить их в базе данных PostgreSQL и экспортировать в файл Excel для дальнейшего использования и анализа.

Описание проекта:
Проект MeterTrack представляет собой графическое приложение, которое включает:
Ввод данных для учета показаний счетчиков воды (холодной и горячей) и электроэнергии.
Сохранение данных в базу данных PostgreSQL.
Экспорт данных в файл Excel.
Просмотр и удаление данных из базы через таблицу в интерфейсе.

Функциональные возможности:
Ввод данных:
Месяц
Счетчик ХВС (холодная вода)
Счетчик ГВС (горячая вода)
Тарифы Т1 и Т2
Дата подачи показаний
Дата оплаты
Банк оплаты
Общий платеж

Отчетность:
Просмотр всех данных о счетчиках в виде таблицы с возможностью прокрутки.
Удаление данных за выбранный месяц.
Экспорт в Excel:
Экспорт всех данных о счетчиках в файл Excel для дальнейшей работы.

Установка
1. Установка зависимостей
Создайте файл requirements.txt с содержимым:
psycopg2
pandas
openpyxl
tkinter
Затем выполните команду для установки зависимостей:
pip install -r requirements.txt

2. Установка PostgreSQL
Установите PostgreSQL. Если он не установлен, скачайте его с официального сайта PostgreSQL
Создайте базу данных с именем db_home или другим по вашему выбору.

CREATE DATABASE db_home;
Создайте таблицу в базе данных для хранения данных о счетчиках:
CREATE TABLE meters (
    id SERIAL PRIMARY KEY,
    month VARCHAR(20),
    cold_water REAL,
    hot_water REAL,
    t1 REAL,
    t2 REAL,
    submission_date DATE,
    payment_date DATE,
    payment_bank VARCHAR(100),
    total_payment REAL
);

3. Конфигурация базы данных в коде
В вашем проекте откройте файл с кодом и настройте параметры подключения к базе данных:
self.db_config = {
    "dbname": "*",  # Название вашей базы данных
    "user": "postgres",    # Ваше имя пользователя PostgreSQL
    "password": "*",    # Ваш пароль
    "host": "localhost",   # Адрес вашего сервера (localhost для локальной базы)
    "port": "5432"         # Порт PostgreSQL
}

4. Запуск приложения
После установки зависимостей и настройки базы данных, вы можете запустить приложение:
python home.py
Структура проекта
/project-folder
    /home.py              # Главный файл проекта
    /requirements.txt     # Файл с зависимостями
    /README.md            # Этот файл

Использование:
Ввод данных: введите данные в форму и нажмите кнопку "Добавить данные" для сохранения в базу данных.
Удаление данных: Выберите строку в таблице и нажмите кнопку "Удалить данные", чтобы удалить запись.
Экспорт в Excel: для выгрузки данных в Excel нажмите кнопку "Экспорт в Excel".
